## 핵심 발견사항

### 1. 환경영향평가 협의 완료 여부 — 미확인

- **2025년 5월 28일 기준**: 환경영향평가법 제25조에 따른 **주민의견 수렴 단계**
- 2025년 6월까지 주민설명회·공청회 허위 개최 논란 진행 중
- **2026년 2월 협의 완료 추정은 확인 불가**
- EIASS 직접 접근이 차단되어 실시간 진행 상태 미확인
- **권고**: 로컬 PC에서 Playwright 브라우저 자동화로 EIASS 직접 조회 필요

### 2. TK신공항 — 사업타당성 근거 무력화 (의견서 논거 5번)

**EIA 주장**: "TK신공항 2025년 착공, 2030년 개항 → 골재 대량 수요 발생"

**현실 (2026.03)**:
- 2025년 착공 **미실현**
- 2026년 착공도 **불투명** (사업비 2,795억 원 정부 예산 미반영)
- 2030년 개항 **사실상 불가능**
- 법적 기반(통합법)은 마련되었으나 **핵심인 자금 조달 미해결**

**의견서 활용**:
> "환경영향평가서에서 사업타당성의 핵심 근거로 제시한 TK신공항 건설 사업은
> 2026년 3월 현재 착공조차 이루어지지 않았으며, 사업비 확보 문제로 착공 시기가
> 전혀 불투명한 상태입니다. 따라서 신공항 건설에 따른 골재 수요 증가를 전제로 한
> 채석단지 확장의 사업타당성은 근거를 상실했습니다."

### 3. HC보광산업 계열사 구조 — 그룹 사익 추구 의심

- HC홈센타(지주회사) 산하 **15개 이상 계열회사** 확인
- 골재 → 레미콘/아스콘 → 건설현장의 **수직계열화 구조**
- 채석단지 확장은 공익이 아닌 **그룹 전체 공급망의 원가절감** 목적 의심
- 정확한 특수관계자 거래 규모는 사업보고서 원문 확인 필요

### 4. 환경오염 실태 — 의견서 보강 자료

| 항목 | 수치/내용 | 출처 |
|------|----------|------|
| 비소 검출 | 원석 1kg당 109mg (토양오염 우려기준 초과) | 서대식 군의원 발언 |
| 폐수처리오니 | 연간 15만 톤 배출 | 서대식 군의원 발언 |
| 골재 운반 차량 | 매일 300여 대 | 서대식 군의원 발언 |
| 주민 피해 기간 | 30여 년 (분진, 진동, 소음) | 군위군수 발언 |
| 토양오염 초과 | 대구환경청 → 군위군 통보 | 서울신문 |

### 5. 주민설명회·공청회 허위 개최 의혹

- 사실상 무산된 주민설명회가 정상 개최된 것으로 기재
- 1·2차 공청회가 정상 개최된 것으로 기재
- 주민이 모르는 공청회 결과 통보서 제출
- **환경영향평가 절차적 하자** → 평가서 자체의 유효성 문제 제기 가능

### 6. 경북대학교병원 소송

- 소송가액: 약 20.6억 원 (손해보상)
- 대구지방법원 진행 중
- 구체적 사건 내용 미확인

## 추가 조치 필요 사항

### 즉시 필요

1. **EIASS 직접 확인**: 로컬 PC에서 브라우저로 EIASS(https://www.eiass.go.kr) 접속하여 "군위 채석단지" 검색
   - 협의진행현황 → 환경영향평가 탭
   - 사업조회 → "군위", "채석", "보광" 키워드
2. **사업보고서 PDF 확보**: DART(https://dart.fss.or.kr) → HC보광산업(225530) → 2025년 12월 결산 사업보고서 다운로드
   - 주석 39번(특수관계자), 주석 43번(우발부채), IV장(경영진단), IX장(계열회사)

### 단기 필요

3. **군위군청 직접 확인**: https://www.gunwi.go.kr 고시공고에서 채석단지 관련 최신 공고
4. **대법원 사건 검색**: 경북대학교병원 vs 보광산업 소송 상세 확인
5. **환경부 정보공개 청구**: 군위 채석단지 환경영향평가 협의 진행 현황 및 협의 내용

6. **연간 15만 톤 폐기물** → 환경 부하 심각
7. **비소 오염** → 중금속 오염으로 인한 건강 위해 우려
