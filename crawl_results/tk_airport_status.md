# TK신공항(대구경북통합신공항) 착공 현황

## 핵심 요약

**EIA에서 "TK신공항 2025년 착공, 2030년 개항"을 사업타당성 근거로 제시하였으나,
2026년 3월 현재 착공은 이루어지지 않았으며, 사업비 확보 문제로 착공 시기가 불투명한 상태.**

---

## 1. 사업 개요

| 항목 | 내용 |
|------|------|
| 사업명 | 대구경북통합신공항 건설 |
| 위치 | 대구광역시 군위군 소보면 ~ 경상북도 의성군 비안면 |
| 부지 면적 | 민간공항 1.87㎢ + 군공항 16.9㎢ |
| 총 사업비 | 약 14조 원 (민간공항 2.7조 + 군공항 등) |
| 주요 시설 | 활주로 3,500m × 1본, 유도로 7본, 여객터미널 12.3만㎡ |
| 사업 목표 | 2026년 착공 → 2030년 개항 |

## 2. 진행 경과

### 완료된 절차
- **2025년 1월 21일**: 국방부, 군공항 이전 사업계획 최종 승인 → 관보 고시
  - 대구시가 사업시행자로서 토지·건축물 보상 자격 획득
- **2025년 12월**: 국토교통부, 민간공항 건설사업 기본계획 고시
  - 국비 2조 7천억 원 투입하여 기존 대구국제공항 7배 규모로 건설
- **2026년 2월**: '대구경북통합특별시 설치를 위한 특별법안' 국회 행안위 통과
  - K2 공군기지 종전부지를 도시혁신구역으로 지정 가능

### 미해결 핵심 과제: 사업비 확보

- **2026년 정부 예산 반영 실패**: 공공자금관리기금 2,795억 원이 2026년도 정부 예산안에 불포함
- **토지보상 차질**: 2026년 토지보상 착수 계획이 예산 미반영으로 연기
- **2030년 개항 사실상 불가능**: 사업비 미확보로 당초 일정 준수 어려움

### 사업비 조달 구조 (대구시 구상)

```
지방채 발행 → 정부(공자기금)가 지방채 매입 → 공항 건설
→ 기존 공항 부지(K2) 개발 수익으로 공자기금 상환
```

- 지방채 초과 발행을 위한 법적 근거: **마련됨** (통합법 통과)
- 공자기금 활용을 위한 특별법 개정안: **미통과**
- 기획재정부: 형평성 이유로 **난색**

## 3. 의견서 활용 포인트 (논거 5번)

### EIA 주장 vs 현실

| 구분 | EIA 주장 | 실제 현황 (2026.03) |
|------|---------|-------------------|
| 착공 시기 | 2025년 | 미착공 (사업비 미확보) |
| 개항 시기 | 2030년 | 사실상 불가능 |
| 사업 단계 | 건설 중 | 토지보상 미착수 |
| 골재 수요 | 대량 발생 예정 | 불확실 |

### 핵심 반박 논리

1. **사업타당성 근거 무력화**: EIA가 TK신공항 건설에 따른 골재 수요 증가를 채석단지 확장의 핵심 근거로 제시했으나, 신공항 착공 자체가 불투명
2. **골재 수요 예측 과대**: 14조 원 규모 건설 프로젝트의 골재 수요를 전제로 한 사업타당성이 현실과 괴리
3. **시간적 불일치**: 채석단지 확장 기간(~2059년)은 신공항 건설 기간과 무관하게 장기적 채석을 목적으로 함
