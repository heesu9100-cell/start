# HC보광산업 소송 현황

## 1. 경북대학교병원 소송 (사업보고서 주석 43번 기재 사항)

### 확인된 정보 (사업보고서 기재 내용 기준)

| 항목 | 내용 |
|------|------|
| 관할법원 | 대구지방법원 |
| 원고 | 경북대학교병원 |
| 피고 | 주식회사 에이치씨보광산업 (구: 주식회사 보광산업) |
| 소송가액 | 2,055,164,470원 (약 20.6억 원) |
| 내역 | 손해보상 |
| 진행상황 | 진행 중 |

### 웹 검색 결과

경북대학교병원과 보광산업 간의 소송에 대한 구체적인 판결문, 뉴스 기사, 법률 정보는 **공개 웹 검색으로 확인 불가**.

가능한 사유:
1. 소송이 진행 중이어서 판결문 미공개
2. 당사자 간 비공개 합의
3. 사건명/당사자 표기가 검색 키워드와 상이

### 추가 확인 방법

| 방법 | URL/경로 |
|------|---------|
| 대법원 종합법률정보 | https://glaw.scourt.go.kr |

| DART 사업보고서 | 주석 43번 우발부채 항목 직접 확인 |

### 소송 배경 추정

- 경북대학교병원이 원고이므로, 병원 측이 보광산업에 손해배상을 청구한 사건
- "손해보상" 내역으로 기재되어 있어, 보광산업의 채석/골재 사업 과정에서 발생한 피해에 대한 보상 청구일 가능성
- 채석단지 운영으로 인한 환경 피해(분진, 진동, 소음 등)와 관련될 수 있으나 확인 불가

## 2. 기타 우발부채 (주석 43번 관련)

### 확인 필요 항목
- 기타 소송 유무
- 약정사항 (차입한도, 담보 제공 내역)
- 금융기관 차입약정
- 지급보증 내역

> **주의**: 위 항목들은 사업보고서 원문(PDF) 확인 시 정확한 수치 파악 가능.
> PDF 파일이 제공되지 않아 웹 검색 결과만으로는 구체적 수치 확인 불가.

## 3. 환경 관련 잠재적 법적 리스크

### 토양오염 관련
- 대구환경청이 "보광산업의 채석단지가 사후영향평가조사서에 따라 **토양오염 우려기준을 초과**한 사실"을 군위군에 통보한 바 있음
- 원석에서 **비소(As) 1kg당 109mg 검출** (서대식 군의원 발언)

### 연간 폐기물 배출
- 석재 및 골재폐수처리오니: **연간 15만 톤** 배출 신고

### 주민 피해 민원
- 30여 년간 진동, 분진, 소음 피해 지속
- 매일 300여 대의 골재 운반 차량으로 인한 교통·먼지 피해
- 지역 20개 사회단체 반대 성명
