## 3. 의견서 핵심 분석 포인트

### 3-1. 계열사 판매 비중
- HC보광산업이 생산한 골재의 **계열사 내부 판매 비중**이 핵심
- 내부 판매 비중이 높을수록 → 채석단지 확장의 공익적 필요성 약화
- "지역 건설 수요 충족"이 아닌 "그룹 사익 극대화"가 실질 목적임을 입증

### 3-2. 이전가격 (골재 판매 단가)
- 관계회사 판매 단가 vs 외부 판매 단가 비교
- 관계회사에 저가 공급 시 → 이익 이전 의혹
- 외부보다 고가 공급 시 → 계열사 부담 전가

### 3-3. 수직계열화 구조의 문제
```
HC보광산업(골재) → HC레미콘/아스콘 계열사(제조) → 건설 현장(납품)
```
- 그룹 전체가 골재→제조→판매의 수직계열화 구조
- 채석단지 확장은 그룹 전체 공급망의 원가절감을 위한 것
- 공익(지역 골재 수급)과 사익(그룹 이윤)의 구분 필요

### 3-4. 지급보증/자금거래
- 대규모 계열사 간 자금거래는 재무 건전성 리스크
- 지급보증 규모가 클 경우 연쇄 부실 위험

## 4. DART 확인 시 추출해야 할 데이터

사업보고서 주석 39번에서 아래 테이블을 찾아 추출:

1. **특수관계자 목록표**: 회사명, 관계 유형(지배기업/종속기업/관계기업 등)
2. **매출·매입 거래 내역표**: 거래 상대방별 매출액, 매입액 (당기/전기 비교)
3. **채권·채무 잔액표**: 매출채권, 미수금, 매입채무, 미지급금 등
4. **자금거래 내역표**: 대여금, 차입금, 이자수익, 이자비용
5. **지급보증 내역표**: 보증 제공 내역, 금액, 만기
