# HC보광산업 계열회사 현황

## 1. 기업 개요

| 항목 | 내용 |
|------|------|
| 회사명 | 주식회사 HC보광산업 (구: 에이치씨보광산업, 보광산업) |
| 종목코드 | 225530 (코스닥) |
| 설립일 | 2004년 8월 27일 |
| 본사 | 대구광역시 북구 |
| 채석단지 | 경상북도 군위군 효령면 매곡리 |
| 주요 사업 | 콘크리트용 부순 골재, 혼합골재, 재활용 아스콘, 일반 아스콘, 레미콘 생산·판매 |
| 채석단지 면적 | 430,854㎡ (산림청고시 제2011-80호) |

### 연혁
- 2004.08: 경북 군위군 효령면 매곡리에서 석재·토사석 채취 및 골재 선별 파쇄업 목적으로 설립
- 2005.01: 대구 달성군 논공읍 공장 인수, 레미콘·아스콘 제조·판매업 추가
- 2015.12: 코스닥 상장 (공모가 4,000원)
- 2025.07경: HC보광산업으로 상호변경

## 2. 그룹 구조

HC보광산업은 **HC홈센타(구: 홈센타홀딩스)** 계열 그룹에 소속.

### 지주회사 구조
- **㈜HC홈센타** (지주회사)
  - 2016년 9월 레미콘 제조 사업부를 물적 분할하여 홈센타를 설립
  - 존속 법인은 ㈜홈센타홀딩스로 변경 후 지주사 전환

### 웹사이트

- HC홈센타: https://www.hchomecenter.co.kr/
- HC그룹: https://hc-group.co.kr/

## 5. 특수관계자 거래 관련 (추정)

> **주의**: 아래 내용은 업종 특성 및 계열사 구조에 기반한 추정. 정확한 수치는 사업보고서 주석 39번에서 확인 필요.

### 예상되는 특수관계자 거래 유형
1. **골재 → 레미콘/아스콘 계열사 판매**: HC보광산업이 생산한 골재를 HC보광레미콘, HC부광산업 등 계열 레미콘·아스콘 회사에 판매
2. **운송/물류 거래**: 골재 운반 관련 거래
3. **자금 대여/차입**: 계열사 간 자금 거래
4. **지급보증**: 계열사 차입금에 대한 지급보증

### 의견서 활용 포인트
- 계열사에 대한 골재 판매 단가가 외부 거래 대비 할인 여부 → 사업타당성 왜곡 가능성
- 계열사 간 순환 거래를 통한 매출 부풀리기 가능성
