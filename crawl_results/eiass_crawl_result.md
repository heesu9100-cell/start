### 군위 채석단지 환경영향평가 진행 상황

**2025년 5월 28일 기준**: 환경영향평가법 제25조에 따른 **주민의견 수렴 단계** 진행 중

```
[환경영향평가 절차]
1. 평가서 초안 작성 ✅ (완료 추정)
2. 주민설명회/공청회 ⚠️ (논란 - 허위 개최 의혹)
3. 주민의견 수렴 결과 공개 ✅ (2025.05.28 군청 공고)
4. 환경영향평가서 작성·제출 ❓ (미확인)
5. 환경부 협의 요청 ❓ (미확인)
6. 환경부 협의·검토 ❓ (미확인)
7. 협의 완료/통보 ❓ (미확인)
```

### 핵심 미확인 사항
1. **환경영향평가서가 환경부에 제출되었는지 여부**
2. **환경부 협의가 요청되었는지 여부**
3. **협의 완료 여부 및 완료일자**
4. **협의 내용 원문**

## 3. 뉴스 기사를 통해 확인된 환경영향평가 현황

### 시간순 정리

| 시기 | 내용 | 출처 |
|------|------|------|
| 2024.01 | 서대식 군의원, 본회의에서 채석단지 확대 반대 발언 | 프레시안 |
| 2025.05.28 | A사(보광산업), 환경영향평가 주민의견 수렴 결과 군에 제출 | 서울신문 |
| 2025.06.05 | 주민 20개 단체, 군청 항의 방문 및 자료 삭제 요구 | 서울신문 |
| 2025.06.06 | 서울신문, 환경영향평가 자료 허위 기재 논란 보도 | 서울신문 |
| 2025.10 | 서대식 군의원, 제293회 임시회에서 재차 우려 표명 | 프레시안 |
| 2026.02경 | 환경영향평가 협의 완료 추정 (미확인) | - |

### 주민의견 수렴 단계의 문제점

1. **주민설명회 허위 개최 의혹**: 주민 반발로 무산된 설명회가 정상 개최된 것으로 기재
2. **공청회 허위 개최 의혹**: 1·2차 공청회가 정상 개최된 것으로 기재, 주민들은 공청회 개최 사실 모름
3. **공청회 결과 통보서 위조 의혹**: 주민이 알지 못하는 통보서가 제출된 것으로 기재
4. **군청의 무비판적 공개**: 사실관계 확인 없이 업체 제출 자료 그대로 공개

## 4. 직접 확인 필요 사항

### EIASS에서 확인해야 할 정보
1. **사업번호**: EIASS 내부 관리번호
2. **현재 상태**: 협의진행중 / 협의완료 / 보완요청 등
3. **협의내용 통보일자**
4. **평가서 원문** (PDF)
5. **협의내용 원문** (PDF)

### 확인 방법
1. EIASS(https://www.eiass.go.kr) → 환경영향평가 → 사업조회
2. 검색어: "군위 채석단지", "보광산업", "효령면 매곡리"
3. 또는: 국민참여 → 협의진행현황 → 환경영향평가 탭에서 검색

### 대안: Playwright/Selenium 브라우저 자동화
웹 크롤러로 직접 접근이 차단되므로, 로컬 PC에서 Playwright 등을 사용한 헤드리스 브라우저 접근 필요.
