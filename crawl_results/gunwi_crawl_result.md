## 2. 웹 검색을 통해 확인된 군위군청 관련 공고 정보

### 2-1. 환경영향평가 주민의견 수렴 결과 공고

| 항목 | 내용 |
|------|------|
| 공고일 | 2025년 5월 28일 |
| 공고 매체 | 군위군청 홈페이지 |
| 공고 내용 | 군위 채석단지 변경 지정에 따른 환경영향평가 항목의 주민 등의 의견 수렴 결과 및 반영 여부 내용 |
| 법적 근거 | 환경영향평가법 제25조(주민 등의 의견 수렴), 동법 시행령 제43조 |
| 제출자 | A사 (보광산업) |

### 2-2. 사업 내용

| 항목 | 내용 |
|------|------|
| 사업명 | 군위 채석단지 변경지정 (확장 및 기간 연장) |
| 위치 | 군위군 효령면 매곡리 산 137 일대 |
| 기존 면적 | 430,854㎡ (43만㎡) |
| 확장 면적 | 702,139㎡ (70.2만㎡) — 약 63% 확장 |
| 기존 기한 | ~2028년 |
| 연장 기한 | ~2059년 (31년 연장) |
| 사업자 | ㈜보광산업 (현 HC보광산업) |

### 2-3. 공고에 대한 주민 반응

- 효령면 매곡 1·2리, 고곡 1·2리, 마시 2리 주민 **강력 반발**
- 주민설명회·공청회 **허위 개최 기재** 의혹
- 군위 효령면 이장협의회 등 **20개 사회단체** 반대 성명
- **군위 석산 개발 주민반대추진위원회** 3차 반대 집회 개최
- 환경부·산림청 항의 방문
- 2025년 6월 5일 군청 항의 방문, 자료 삭제 요구

### 2-4. 군위군수 대응

김진열 군위군수:
- "30여 년간 진동·분진 피해를 입은 주민들이 또다시 피해를 입어서는 안 된다"
- "사실 관계를 명확히 밝혀 환경부 등 관계 기관과 엄중히 대응하라" 지시

## 3. 추가 확인된 군위군 관련 정보

### 토지이음 고시 정보
- 경상북도 2009-214호 (2009.04.20) — 군위 채석단지 최초 지정 관련 고시로 추정
- 상세 내용은 첨부 PDF에만 포함, 웹에서 본문 확인 불가

### 군위군의회 동향
- **서대식 부의장 (2024.01.23)**: 본회의에서 채석단지 확대·연장 적극 반대
  - 19년간 소음, 분진, 매일 300대 골재 운반 차량 피해 지적
  - 원석 비소 109mg/kg 검출 (토양오염 우려기준 초과)
  - 연간 15만 톤 골재폐수처리오니 배출
  - 2016~2017년 군유림과 보광산업 산 맞교환 사전 통보 부재 비판

- **서대식 군의원 (2025.10)**: 제293회 임시회에서 재차 우려 표명
  - "효령면 채석단지 확장과 군위읍 산업단지 조성이 연이어 진행"
  - "환경오염 민원에도 통제·감시체계가 작동하지 못하고 있다"

## 4. 직접 확인 필요 사항

군위군청 홈페이지(https://www.gunwi.go.kr)에서 직접 확인해야 할 사항:

1. **고시공고 게시판**: 채석단지 변경지정 관련 최신 공고
2. **환경영향평가 초안 공고**: 원문 PDF 확보
3. **주민의견 수렴결과 공개**: 원문 PDF 확보
4. **협의내용 관련 공고**: 환경부 협의 결과 공고 여부
5. **실과소 게시판**: 산업과/환경과 관련 공지

### 검색 키워드
- 채석단지, 환경영향평가, 보광, 효령, 채석
